Raj Shamani YouTube Channel Analysis
Analyzing the latest 100 long-form videos to understand what drives YouTube performance.

Tools: Python | YouTube Data API | Pandas | Data Analysis | HTML/CSS/JavaScript

Project Overview

I analyzed the latest 100 long-form videos from Raj Shamani's YouTube channel to understand:

Which topics perform best?
Which upload days get more views?
Does video duration affect performance?
Which videos have the highest engagement?
What recommendations can be made from the data?
What I Did

→ Collected video data using the YouTube Data API

→ Analyzed views, likes, comments, duration and engagement

→ Created categories based on guest topics using keyword matching

→ Performed category, upload-day and duration analysis

→ Built an interactive dashboard

→ Generated insights and recommendations from the analysis

Key Insights

Geopolitics & War was the strongest category in this selection, with 5.19Cr total views across 21 videos.

Thursday had the highest average views, at around 22.6L views per video.

Videos 30+ minutes showed the highest average engagement rate at 2.69%.

The highest-viewed video in the dataset reached approximately 1.53Cr views.

Recommendations

→ Focus more on topics that consistently generate high views.

→ Test more Geopolitics & War content.

→ Experiment with Thursday uploads.

→ Track engagement along with views instead of looking at views alone.
